# Support

MultiRAG Clean is maintained as an open-source project.

## Questions and usage help

Before opening an issue:

1. Read the README and deployment documentation.
2. Check existing issues for the same problem.
3. Reproduce the problem with the smallest possible configuration.

For reproducible defects, open a bug report using the repository issue template.

For concrete improvements, open a feature request.

## Security issues

Do not report suspected vulnerabilities in a public issue. Follow
[SECURITY.md](SECURITY.md).

## Scope

Maintainer support is best-effort. Requests are easier to act on when they
include the exact version or commit, operating system, Python version,
deployment mode, relevant provider configuration, logs with secrets removed,
and minimal reproduction steps.
