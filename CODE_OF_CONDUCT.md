# Community Code of Conduct

MultiRAG Clean aims to keep technical collaboration professional, constructive,
and accessible to contributors with different backgrounds and levels of
experience.

## Expected behavior

Participants should:

- discuss technical ideas and code on their merits;
- give specific, actionable, and respectful review feedback;
- assume good faith while still verifying technical claims;
- respect privacy and never publish another person's secrets or private data;
- keep issue and pull-request discussions relevant to the project;
- acknowledge mistakes and correct them when evidence changes.

## Unacceptable behavior

The project does not accept harassment, threats, discriminatory abuse,
doxxing, deliberate disruption, or publication of credentials, private data,
or exploit details that should be handled through the security process.

## Enforcement

The primary maintainer may edit, hide, lock, or remove content and may restrict
participation when behavior materially harms contributors, users, or project
security.

For security vulnerabilities, use [SECURITY.md](SECURITY.md) rather than public
issues. For ordinary project questions, use the support and contribution
channels described in [SUPPORT.md](SUPPORT.md) and
[CONTRIBUTING.md](CONTRIBUTING.md).
