# Code of Conduct

MultiRAG Clean is intended to be a professional, technically focused, and
welcoming open-source project.

## Expected behavior

Participants should:

- communicate respectfully and focus criticism on ideas, code, and behavior;
- give actionable technical feedback and assume good faith where reasonable;
- respect differing experience levels, backgrounds, and communication styles;
- avoid publishing private information, credentials, or sensitive data;
- disclose conflicts of interest when they materially affect a review or
  contribution.

## Unacceptable behavior

Harassment, threats, discriminatory language, deliberate intimidation,
personal attacks, doxxing, sexualized conduct, or sustained disruption of
project collaboration are not acceptable.

Technical disagreement is welcome. Abuse directed at a person is not.

## Scope

This policy applies to repository issues, pull requests, reviews, discussions,
and other project-controlled communication spaces.

## Enforcement

Maintainers may edit or remove content, close or lock discussions, reject
contributions, or restrict participation when behavior materially violates
this policy.

If a conduct concern includes sensitive personal information, do not publish
that information in a public issue. Contact the maintainer through GitHub using
the least-public channel reasonably available.

Enforcement decisions should be based on documented behavior and project
safety, not on disagreement over technical choices.
